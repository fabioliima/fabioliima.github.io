# Fábio Lima · Data Engineering

Portfólio bilíngue com estudos de caso de Engenharia de Dados, arquiteturas animadas e decisões técnicas.

**Site:** https://fabioliima.github.io/

- Português: https://fabioliima.github.io/?lang=pt
- English: https://fabioliima.github.io/?lang=en

## Projetos

- **Airflow, dbt e MySQL** — ingestão por APIs e webhooks, modelagem dimensional, qualidade de dados, observabilidade e CI/CD.
- **Azure Data Factory e Azure SQL** — ingestão parametrizada por tabela de controle, cargas incrementais, curadoria em T-SQL e consumo no Power BI.

Os estudos foram adaptados para apresentação pública. Os exemplos de expansão aparecem identificados no case Azure. Nenhuma conexão com os ambientes das empresas é realizada pelo site.

## Editar e executar

O site usa HTML, CSS e JavaScript, sem etapa de build. Para visualizar localmente:

```sh
python -m http.server 8765
```

Acesse http://localhost:8765. Os textos em português estão em `index.html` e a tradução está em `app.js`. Os quatro GIFs são selecionados conforme o idioma.
