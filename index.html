PLATAFORMA DE DADOS · ORQUESTRAÇÃO E ANALYTICS

Integrações, eventos e uma camada analítica centralizada.

Uma arquitetura que reúne ERP, CRM, APIs, banco da aplicação e planilhas em um Data Warehouse, com transformação e qualidade de dados.

  • Python
  • Apache Airflow
  • dbt
  • MySQL
  • FastAPI
  • GitHub Actions
  • Microsoft Fabric

O desafio

Consolidar dados de diferentes sistemas para sustentar indicadores compartilhados, com processos de carga rastreáveis e regras de negócio consistentes.

Minha atuação

Desenvolvimento de DAGs e integrações em Python, estruturação do DW em MySQL e transformações SQL. Evolução para dbt e webhooks, com revisão de código, testes e automação de entrega.

A entrega

Camadas de staging, controle, fatos e dimensões, com dados disponíveis para Power BI e consumidores analíticos. Monitoramento de execução e alertas apoiam a sustentação dos pipelines.

Decisões técnicas e operação

Clientes de API reutilizáveis

Autenticação, paginação, timeout e retry concentrados por fonte. As DAGs reaproveitam essa lógica ao extrair cada entidade.

Incremental com rastreabilidade

Configuração, watermark e logs de execução registram o avanço da carga. As transformações aplicam deduplicação, regras de negócio e histórico dimensional.

Qualidade e entrega contínua

Testes de unicidade, campos obrigatórios e integridade referencial. GitHub Actions valida código e DAGs, apoiando deploy e rollback.

Acesso e observabilidade

Credenciais em Airflow Connections e GitHub Secrets, acesso de leitura para consumo e alertas de falha com Issues no GitHub.

MICROSOFT AZURE · DATA WAREHOUSE E BI

Ingestão orientada por metadados, do ADF ao Power BI.

Pipelines parametrizadas integram APIs e organizam cargas por data, rota e página. Uma tabela de controle centraliza a configuração da ingestão.

  • Azure Data Factory
  • Azure SQL
  • T-SQL
  • Key Vault
  • Logic Apps
  • Azure DevOps
  • Power BI

O desafio

Consumir diferentes rotas de APIs, coordenando paginação e janelas de datas, e disponibilizar dados tratados para análise com controle de custos de infraestrutura.

Minha atuação

Desenvolvimento de pipelines ADF e transformações em stored procedures, parametrização por tabela de controle e tratamento de falhas. Versionamento no Azure DevOps e integração com Key Vault e Logic Apps.

A entrega

Cargas incrementais de APIs para staging e processamento até as tabelas analíticas. Dataflows e a camada semântica disponibilizam os dados para relatórios em Power BI.

Decisões técnicas e operação

Controle centralizado

Endpoints, filtros, limites de paginação e LAST_LOAD na tabela de controle. Pipelines encadeadas percorrem datas, rotas de transporte e páginas de cada API.

Reprocessamento de sete dias

A janela parte de LAST_LOAD menos sete dias para recuperar alterações recentes. Procedures tratam registros e aplicam as regras antes da carga analítica.

SQL serverless e alertas

Azure SQL de 0,5 a 2 vCores, com pausa após uma hora de inatividade. A pipeline retoma o banco antes da carga. Falhas registradas acionam e-mails via Logic Apps.

Modelo de referência e expansão

O diagrama apresenta SAP local com runtime auto-hospedado, planilhas e agentes de IA como possibilidades de expansão. Schemas FATO/DIMENSÃO e data marts departamentais ilustram a organização analítica.
